# US-06 — Responsive Layout

**As a visitor browsing on a phone or tablet, I can use ScentStore comfortably so that the experience is not degraded on smaller screens.**

| Field | Value |
|-------|-------|
| Complexity | S |
| Dependencies | US-02, US-03, US-04, US-05 |

## Acceptance Criteria

1. The header, both carousels, and the product grid display correctly across viewports from 320px to 1440px+.
2. No horizontal scroll appears at any standard viewport width.
3. The category filter dropdown remains accessible and usable on mobile.
4. Carousel touch/swipe navigation works on mobile devices.
5. Carousel shows 1 item at a time on viewports below 768px.
